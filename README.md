University Course Management System
Overview

A MySQL project designed to manage university departments, students, courses, instructors, and enrollments. It demonstrates basic and advanced SQL queries for data management and analysis.

Technologies Used
MySQL
SQL
Database Tables
Departments: Stores department information.
Students: Stores student details.
Courses: Stores course names, credits, and department references.
Instructors: Stores instructor details and department references.
Enrollments: Connects students with courses.
SQL Concepts Covered
Database and table creation
INSERT, UPDATE, and DELETE operations
SELECT queries and filtering
Primary and foreign keys
INNER JOIN and LEFT JOIN
Aggregate functions: COUNT, AVG, MAX, SUM
GROUP BY and HAVING
Subqueries
String and date functions
CASE statements
Window functions and running totals
How to Run
Install MySQL Server or MySQL Workbench.
Open the SQL script in your MySQL client.
Execute the statements in order.
Review the results and experiment with the queries.
Learning Outcomes
Understand relational database design.
Practice SQL queries and table relationships.
Analyze data using joins and aggregate functions.
Work with date functions, subqueries, and window functions.
